# @financial-app/http-client

Financial App API HTTP client generated with [HeyAPI](https://heyapi.dev) from the OpenAPI specification.

## Features

- **Type-safe**: All endpoints and responses are fully typed
- **TanStack Query integration**: Generated query options and mutation options
- **Fetch API**: Lightweight client based on native Fetch API
- **Auto-generated**: Regenerate anytime with `pnpm generate`

## Installation

This package is part of the monorepo. Dependencies are managed at the workspace level.

```bash
pnpm install
```

## Usage

### Client Configuration

Configure the client once at app startup:

```typescript
import { client } from '@financial-app/http-client/client'

client.setConfig({
  baseUrl: 'http://localhost:3001',
  auth: () => accessToken,
})
```

### SDK Functions

```typescript
import { getTransactions, getBalance, getBudgets } from '@financial-app/http-client'

// Get balance
const { data } = await getBalance()

// Get transactions with pagination
const { data: txns } = await getTransactions({ query: { page: 1, limit: 10 } })

// Get budgets
const { data: budgets } = await getBudgets()
```

### With TanStack Query

```typescript
import { useQuery } from '@tanstack/react-query'
import { getTransactionsOptions, getBalanceOptions } from '@financial-app/http-client'

// In a React component
const { data, isLoading } = useQuery(getBalanceOptions())

const { data: txns } = useQuery(
  getTransactionsOptions({ query: { page: 1, limit: 10 } })
)
```

## Regenerating the Client

When the API contract changes, regenerate from root:

```bash
pnpm api:generate-client
```

This runs the full pipeline: Zod schemas -> openapi.yaml -> HeyAPI client.

Or regenerate just the client (if openapi.yaml already exists):

```bash
pnpm --filter @financial-app/http-client generate
```

## File Structure

```
packages/http-client/
  src/
    client/                   # Generated by HeyAPI (do not edit, gitignored)
      client.gen.ts           # HTTP client instance
      sdk.gen.ts              # SDK functions
      types.gen.ts            # TypeScript types
      @tanstack/
        react-query.gen.ts    # TanStack Query options
    types/
      errors.ts               # API error interface
    index.ts                  # Package entry point
  scripts/
    add-ts-nocheck.js         # Post-generation script
  openapi-ts.config.ts        # HeyAPI configuration
  package.json
  tsconfig.json
```
