# Project Origin and Vision

## Observations

- [origin] Personal Finance app from a Frontend Mentor challenge — but taken far beyond the challenge scope
- [vision] Cross-platform design system targeting React Native (Expo) and React web (React Router)
- [vision] Production-grade quality throughout — not a tutorial project, not a prototype
- [language] TypeScript strict everywhere — no explicit `any`, no shortcuts
- [approach] Build the design system first, then the apps on top — tokens -> config -> UI -> apps
- [approach] Every component cross-platform from day one — not "build web, then port to native"
- [learning] Three mobile apps (bare RN, Expo managed, ejected) kept for comparison and learning
- [tool] Claude Code as AI pair programmer throughout — skills, reviews, memory across sessions
- [product] Full spec in `files/docs and context/PERSONAL_FINANCE_ANALYSIS_EN.md`
- [design] Proto screenshots in `files/proto/screen and readme/` — desktop, tablet, mobile targets
