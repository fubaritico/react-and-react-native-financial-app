# Branding — Pouch Identity

## Observations

- [name] App name: Pouch — personal finance pouch/bourse metaphor
- [logo] Drawstring pouch, minimalist, monochrome grey-900 (#201f24)
- [logo] Scales from 24px (header) to 1024px (app icon) without losing clarity
- [tool] Logo designed via Recraft AI, prototyped in `files/proto/logo/`
- [animation] Splash: pouch falls + bounces (squash & stretch), 4 coins drop in, pouch vibrates, 1s rest
- [format] Lottie animation created in LottieFiles Creator from SVG source
- [format] `.lottie` (DotLottie ZIP) on native, raw Lottie JSON on web
- [tone] Sober, clear, practical — matches Figma design language from Frontend Mentor challenge
- [walkthrough] Onboarding slideshow shows 4 real screens (Overview, Transactions, Budgets, Pots) with mock data via isolated QueryClientProvider
